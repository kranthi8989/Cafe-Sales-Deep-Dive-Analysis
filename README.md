#  Cafe Sales Analytics Dashboard

##  Project Overview

This project focuses on performing a deep-dive analysis of a Cafe Sales dataset and building an interactive dashboard to uncover valuable business insights.

---

##  Objectives

- Define and analyze key business KPIs.
- Identify top-selling and high-revenue products.
- Analyze sales trends over time.
- Evaluate location-wise performance.
- Study customer payment preferences.
- Create an interactive dashboard for business decision-making.

---

##  Deep-Dive Analysis

The project includes detailed analysis of:

### Product Performance Analysis
- Most sold products
- Highest revenue-generating products

### Sales Trend Analysis
- Daily revenue trends
- Monthly revenue trends

### Location Analysis
- Revenue comparison across different locations

### Payment Method Analysis
- Customer payment preferences
- Revenue contribution by payment method

### Correlation Analysis
- Relationship between quantity sold and revenue generated

- Location

##  Key Insights

- Identified the most popular products based on quantity sold.
- Determined the highest revenue-generating menu items.
- Analyzed sales performance across multiple locations.
- Evaluated customer payment behavior.
- Discovered trends in daily and monthly revenue patterns.
